# GPS Profesional 2029

Bienvenido a mi proyecto web personal: un “Professional GPS” interactivo que representa mi visión profesional a futuro.

## Descripción

Esta aplicación está diseñada para mostrar de forma creativa y visual mi ruta profesional a 3 años vista. A través de diferentes secciones, exploro:

- dónde quiero estar profesionalmente
- qué habilidades quiero desarrollar
- qué retos espero enfrentar
- qué me gustaría que la gente recuerde de mi trabajo

La idea principal es convertir una reflexión profesional en una experiencia web atractiva, moderna y personalizada.

## Objetivo

Crear una interfaz interactiva que permita expresar de manera clara y visual mi futuro profesional, usando un enfoque creativo, tecnológico y personal.

## Características

- Navegación lateral con accesos a cada sección
- Diseño visual con estilo neobrutalista
- Temas personalizables
- Experiencia responsive para escritorio y móviles
- Animaciones suaves para mostrar contenido de forma dinámica
- Persistencia del tema mediante almacenamiento local del navegador

## Estructura del proyecto

- [index.html](lRawec.github.io/index.html): página de entrada y redirección inicial
- [main_interface.html](lRawec.github.io/main_interface.html): interfaz principal de navegación
- [destiny.html](lRawec.github.io/destiny.html): sección de destino profesional
- [skills.html](lRawec.github.io/skills.html): sección de habilidades
- [challenges.html](lRawec.github.io/challenges.html): sección de retos y crecimiento
- [legacy.html](lRawec.github.io/legacy.html): sección de legado profesional
- [sidebar.html](lRawec.github.io/sidebar.html): componente reutilizable del sidebar
- [style.css](lRawec.github.io/style.css): estilos globales y temas visuales

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript vanilla
- Tailwind CSS
- Google Fonts
- Material Symbols

## Notas
Este proyecto es una web estática, por lo que no requiere compilación ni dependencias complejas. Para una mejor experiencia, se recomienda abrirlo desde un servidor local en lugar de abrir los archivos directamente desde el sistema.
